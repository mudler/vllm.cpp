## Problem and scope

The published Gemma 3 4B text configuration declares linear RoPE with factor
eight. `LoadHfConfig` rejects it before model loading. The Gemma 3 forward also
uses unscaled `RopeNeox`, so accepting the configuration alone is incorrect.
The failure is reproduced through `vllm_engine_load` on the unmodified base.

Add the linear-scaling rotary leaf and factory arm. Validate its required
factor. Route the newly admitted Gemma 3 linear configuration through cached
BF16 rotary values on both global and sliding layers: global layers use linear
scaling and the configured theta, sliding layers use default scaling and the
local theta. Preserve the existing path for previously admitted configurations.
Do not change quantization, attention arithmetic, or the checkpoint's parameters.

## Upstream and design

Primary: vLLM `e126687a9a828d513c01a07cd69f025f27d63280`.
Sources:

- `vllm/model_executor/layers/rotary_embedding/linear_scaling_rope.py:37-127`:

- `vllm/model_executor/models/gemma3.py:159-189`: per-layer rotary selection.
- `tests/kernels/core/test_pos_encoding.py`: module-cache and rotation gates.

Use the existing `RotaryEmbedding` base and `get_rope` cache. Expose scalar and
multiple-factor constructors as in the primary leaf. The typed model config
continues to represent one factor. Store the two new Gemma caches with model
weights and use `ResidentWeight` plus `RopeFromCache` at the existing call site.
BF16 is the model cache dtype; FP32 is only the upstream cache construction
arithmetic. Multiple factors do not add a new LoRA runtime capability.

## Risks and stop conditions

The global cache has `ceil(max_position * factor)` rows, as `torch.arange` does.
Reject invalid factors and unrepresentable allocation sizes. Preserve the
primary's operation order: dividing the position is not always numerically
identical to dividing inverse frequency. Do not widen tolerances to hide a
numeric mismatch. Any additional forward mismatch needs a specific measured
cause and local issue. Do not merge without independent review.
