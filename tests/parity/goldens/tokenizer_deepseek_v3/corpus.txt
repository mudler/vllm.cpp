# Tokenizer parity corpus — DeepSeek-V3/V4-Flash pre-tokenizer (issue #1924).
# One entry per line. Format rules (implemented identically by
# tools/parity/dump_tokenizer.py, tools/parity/verify_tokenizer_gguf.py and
# examples/tokenize/main.cpp):
#   - Lines starting with '#' are comments and are skipped.
#   - An empty line is an entry: the empty string.
#   - Escapes: \n = LF, \r = CR, \t = TAB, \\ = backslash. Any other
#     backslash sequence is an error (fail loud on typos).
#
# This family is a FOUR-stage Sequence pipeline, three of them Split, not one
# alternation regex:
#   0. Split(\p{N}{1,3})                    -- digit groups of at most three
#   1. Split([<Hiragana+Katakana+CJK>]+)    -- U+3040-U+30FF, U+4E00-U+9FA5
#   2. Split(<six-alternative regex>)       -- words, punctuation, whitespace
#   3. ByteLevel(use_regex=false)           -- byte mapping, splits nothing
# Stage ORDER is load-bearing: stage 2's alternation matches NO digit at all
# (\p{N} is outside every one of its six alternatives), so a digit only ever
# becomes its own piece because stage 0 already isolated it; and its rule-2
# prefix class [^\r\n\p{L}\p{P}\p{S}]? would otherwise glue a trailing digit
# onto the following word ("abc123def" -> "abc" + "123def" instead of
# "abc" + "123" + "def"). Every section below exists to hold one of the six
# alternatives, one stage boundary, or one codepoint-class edge.
#
