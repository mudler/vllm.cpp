# Tokenizer parity corpus for the GPT-4o / o200k pre-tokenizer ("llama4" GGUF
# pre name), issue #347. One entry per line.
# Format rules (implemented identically by tools/parity/dump_tokenizer.py,
# tools/parity/verify_tokenizer_gguf.py and examples/tokenize/main.cpp):
#   - Lines starting with '#' are comments and are skipped.
#   - An empty line is an entry: the empty string.
#   - Escapes: \n = LF, \r = CR, \t = TAB, \\ = backslash. Any other
#     backslash sequence is an error (fail loud on typos).
# Beyond the usual axes (ASCII prose, code, CJK, emoji, RTL, space and newline
# runs, digit runs, special tokens mid-text, empty string) this corpus targets
# what makes GPT-4o NOT kLlama3 and NOT kQwen2: CamelCase boundaries, the
# contraction as a word SUFFIX, `/` in the punctuation-run tail, the minor
# letter categories (Ll vs Lu/Lt vs Lm/Lo) and combining marks.
#
# --- ASCII prose ---
The quick brown fox jumps over the lazy dog.
Hello, world! This is a plain ASCII sentence with punctuation: commas, semicolons; and (parentheses).
A
Supercalifragilisticexpialidocious antidisestablishmentarianism
